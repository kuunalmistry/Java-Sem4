<h2>▶️ Getting Started</h2>

<h3>Prerequisites</h3>

<ul>
<li>Java JDK 8 or later</li>
<li>Java-compatible IDE or code editor</li>
<li>Basic understanding of Java programming</li>
</ul>

<h3>Clone the Repository</h3>

<pre>
git clone https://github.com/KuunalMistry/Java-Practicals-Sem-4.git
</pre>

<h3>Navigate to the Repository</h3>

<pre>
cd Java-Practicals-Sem-4
</pre>

<h3>Compile a Java Program</h3>

<pre>
javac ProgramName.java
</pre>

<h3>Run the Program</h3>

<pre>
java ProgramName
</pre>

<p>
Individual programs can also be opened and executed using
IntelliJ IDEA, VS Code, Eclipse, or another Java-compatible IDE.
</p>
